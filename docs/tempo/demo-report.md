# Remote demo inventory report

Demo Kurulumu now offers Makine bilgilerini getir alongside the unchanged target-side installation panel. The read-only mode queries the same existing inventory on the authorized remote Windows terminal account and returns Base64-encoded JSON as a nonce-tagged TDI frame. Base64 here transports result data only; it is not used to execute code. No SQL setup, region changes or elevation are initiated. After reception, the operator dialog replaces terminal command output with selectable computer/Windows, SQL instance/version/service, SSMS, locale/date/time and Java/AKIS details. Terminal authorization is still required. User locale belongs to the report account and may differ from the interactive desktop account. Failure output remains visible in the terminal.

Regression surface: tempo-demo.ps1 adds an early read-only exit before loading Windows Forms; the existing setup path is otherwise unchanged. tools_catalog.dart optionally invokes that mode synchronously. library_button.dart adds the choice and an optional terminal observer/report display, while retaining existing download progress and terminal authorization. demo_inventory.dart alone parses bounded frames and formats results. Two regression tests cover chunked remote data/target identity and read-only launch; CI adds them to the UI-only Windows build. No Rust, FFI or native DLL changes. Target Windows inventory/UAC tests remain required.

The current terminal modal blocks controls in its owner window. It does not add a global one-device connection limit. Switching another device from the main operator window should be tested separately; no modal/background lifecycle change is included here.
